I build software that ships. At [Nuvio](https://nuvio.co.za/), where I'm Technical Director, that means agent tooling and internal systems — the practical infrastructure teams actually use. As an independent consultant I work with operators in the wildlife industry: lab tooling, data, and the small instruments that make remote field work possible.

I co-founded [Rhino Repro](https://rhinorepro.org/) in 2016 to apply assisted reproductive techniques — oocyte recovery, ICSI, cryopreservation — to preserve the white and black rhino.
